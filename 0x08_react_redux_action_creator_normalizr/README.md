# React Redux Action Creator and Normalizr

This project focuses on using Redux action creators and Normalizr in a React application.

## Learning Objectives

- Understand the purpose of Normalizr
- Normalize nested JSON data
- Create Redux action types
- Create Redux action creators
- Bind action creators
- Use Redux Thunk for asynchronous actions
- Handle login success and failure actions
- Test Redux actions and asynchronous action creators

## Tasks

- Task 0: Read data from a JSON file
- Task 1: Normalize nested notification data with Normalizr
- Task 2: Filter normalized notification data
- Task 3: Create course action types and action creators
- Task 4: Create UI action types and action creators
- Task 5: Create notification action types and action creators
- Task 6: Create bound action creators
- Task 7: Implement asynchronous login actions with Redux Thunk
