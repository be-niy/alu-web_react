# React Redux Reducer and Selector

This project focuses on Redux reducers, Immutable.js, Normalizr, and selectors in a React application.

## Learning Objectives

- Understand the purpose of reducers in Redux
- Understand why reducers should remain pure
- Avoid state mutation within reducers
- Use Immutable.js to manage state
- Use Normalizr to normalize application data
- Create and use selectors to access Redux state efficiently

## Tasks

- Task 0: Write a basic reducer
- Task 1: Use Immutable for the UI reducer
- Task 2: Create a reducer for courses
- Task 3: Create the reducer for notifications
- Task 4: Use Normalizr and Immutable
- Task 5: Create selectors
